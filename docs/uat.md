# UAT checklist

| Test | Expected result |
|---|---|
| Run generator and pipeline | Raw, curated, web and quality-report outputs are produced |
| Run automated test | Pipeline completes and reconciliation difference is zero |
| Open dashboard | Four KPI cards, trend, risk list, exceptions and category mix render |
| Choose a supplier tier | KPI cards and risk list reflect only that tier |
| Inspect exception queue | High-value late, partial and price-variance cases are visible |
| Review reconciliation report | Status is PASS and source/reporting spend difference is zero |

## Demo walkthrough

Start at the OTIF card, compare it against the 92% target, filter to a supplier tier, then use the risk list and exception queue to identify an owner-led follow-up. Close by reviewing category concentration before deciding whether a sourcing review is needed.
